Add a game

1. In Windows Explorer, copy the video file (an .mp4 from the camera) into the clips folder on the storage card:
D:\...\clips
2. Come back here and press Refresh. The game appears as a card, ready to run.
A full game is about 2 GB; the copy takes a few minutes. Give the file a short name without spaces, like game4.mp4.
